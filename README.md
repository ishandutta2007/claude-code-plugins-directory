## 🔍 What Is the Claude Code Plugins Directory?

The **Claude Code Plugins Directory** is a community-driven, open-source repository that catalogs plugins and extensions compatible with Anthropic's Claude AI assistant. Inspired by the [official Claude plugins repository](https://github.com/anthropics/claude-plugins-official), this project serves as a broader, community-curated collection of tools that extend Claude's capabilities.

### Why Use This Directory?

- **Discover Claude plugins** — Browse a curated list of community-built Claude AI plugins and extensions.
- **Share your Claude plugin** — Submit your own plugin to reach thousands of Claude developers and users.
- **Open source & community-driven** — All plugins are open source and reviewed by the community for quality and safety.
- **Covers diverse use cases** — SEO tools, Google Ads integrations, developer utilities, content optimization, schema markup, analytics, and more.

## 🤝 How to Contribute a Claude Plugin

Contributions are highly encouraged! If you have a Claude-compatible plugin you'd like to add to the directory, follow these steps:

1. **Fork the repository.**
2. **Add your plugin:** Create a new folder for your plugin under the `plugins/` directory. Include a `README.md` with detailed usage instructions, installation steps, and examples.
3. **Update the main directory:** Add a row for your plugin to the [plugin table](#-claude-plugin-directory--available-plugins) in this `README.md` file.
4. **Submit a Pull Request:** Open a PR with a clear description of your plugin and the changes you've made.

Please see the [`CONTRIBUTING.md`](CONTRIBUTING.md) file for more detailed guidelines.

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><strong>What types of plugins are accepted?</strong></summary>

Any open-source plugin, extension, skill, or tool that is compatible with Anthropic's Claude AI — including Claude Code plugins, MCP servers, Claude skills, and workflow integrations.
</details>

<details>
<summary><strong>How are plugins reviewed?</strong></summary>

All submissions are reviewed by the community via Pull Requests. We check for basic code quality, safety, and accurate documentation before merging.
</details>

<details>
<summary><strong>Can I submit a commercial or closed-source plugin?</strong></summary>

This directory focuses on open-source plugins. If your plugin has an open-source core with optional paid features, it is welcome.
</details>

<details>
<summary><strong>How is this different from the official Claude plugins repository?</strong></summary>

The [official repository](https://github.com/anthropics/claude-plugins-official) is maintained by Anthropic. This directory is a community-curated, broader collection that accepts plugins from any developer.
</details>
